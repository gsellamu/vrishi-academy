# VRishi Session Anatomy — Kappasinian Model (v1.0)

Derived from Jeeth's HMI workbooks: 201-9 First Consultation (Melton), Practicum Scripts,
101 ToM, Hypnotic Modalities, Clinical Note Taking, E&P Suggestibility/Sexuality scoring.
All wording in this repo is original; HMI/Panorama workbook text is not reproduced.

## Section model

SESSION → SECTIONS → STAGES → STEPS. Three sections in every session:

| Section | Purpose | First-session share |
|---|---|---|
| A. COGNITIVE | Rapport, intake, expectation-setting, critical-mind preparation, message-unit buildup | ~28 min |
| B. HYPNOTIC | Induction → deepening → therapeutic suggestion → PHS → emerge | ~22 min |
| C. INTEGRATION | Debrief, PHS verification, homework, rebook | ~5 min |

## First session — stage sequence (target 50–55 min)

| # | Stage | Steps | Min | Notes |
|---|---|---|---|---|
| 1 | Presenting issue | open-ended elicitation → closed-ended anchoring → note keywords | 10 | L.O.V.E. (Listen, Observe, Verify, Empathize); interpret from the client's frame, not yours |
| 2 | Pre-induction talk | dispel myths → set expectations → define hypnosis → link to issue | 3 | begins message-unit buildup |
| 3 | Suggestibility testing | finger-spread → heavy/light → questionnaires scored | 5 | outputs physical_pct / emotional_pct (sum = 100) |
| 4 | Theory of Mind | conscious/subconscious/critical-area diagram → slot client's issue into the model | 5 | answer the 4 critical-mind questions: what is the problem, why is it there, what must change, how we will change it |
| 5 | Questionnaire | complete both sides | 5 | continued message-unit buildup |
| 6 | Primary induction | arm-raising (inferred variant for Emotionals, literal for Physicals) → countdown 5→0 → deep-sleep cue → eye/arm challenge → chair-side deepeners | 10 | around the 30-minute mark; first session must use arm-raising |
| 7 | Progressive relaxation | move to recliner → PR sweep → optional staircase | 5 | recording of the hypnotic portion starts here |
| 8 | Therapeutic suggestions | Say it (literal or inferred) → See it (visualize) → Feel it (embody); optional venting-dream suggestion | 5 | suggestion mode follows suggestibility |
| 9 | PHS to re-hypnosis | emerge (count 0→5) → immediate re-hypnosis via finger-spread to verify the post-hypnotic cue | 5 | conditions rapid re-entry for session 2+ |
| 10 | Homework + rebook | assign homework, schedule next session | — | |

Operating rule from the workbooks: **Physicals need to feel hypnosis; Emotionals need to feel understood.**

## Subsequent sessions

1. Prior-week review (peel-the-onion; track recurring keywords in notes)
2. Open-ended discovery → closed-ended anchoring of each realization
3. Optional diagnostic tools: corrective therapy, pendulum, dream therapy, Paris window
4. Reserve ≥ 20 min for the hypnotic section (rapid re-induction via PHS cue)
5. Suggestions per current pillar plan → emerge → homework

## Pillars & thinking-ahead

Pillars = cognitive/emotional supports built **before** hypnosis so the critical area accepts
the coming suggestions. Thinking-ahead = pre-seed anchors during the cognitive section
(e.g., establish a calm "special place" conversationally before any desensitization work).
Every session template carries a `pillar_plan` list and each suggestion must trace to a pillar.

## Modality synergy checklist (any technique bolted into stage 8)

1. Authority / one-upmanship — practitioner frame
2. Doctrine / paradigm / translogic — a believable explanatory model for the client
3. Overload / internal experience — message units → escape into hypnosis

## E&P axes (scoring per Panorama instructions)

- Suggestibility: Q1(+Q2) weighted scoring → grid lookup → **physical_pct**; emotional_pct = 100 − physical_pct.
- Sexuality (relationship behavior): same method → **physical_sx_pct** / emotional_sx_pct.
- Cross-modifier: Physical-sexual with emotional suggestibility > 40 → +10 physical_sx_pct;
  Emotional-sexual with physical suggestibility > 40 → +10 emotional_sx_pct.
- E&P relationship framing is used only when relevant to the presenting issue; it is not required intake in session 1.

## Documentation hooks (Clinical Note Taking)

Per session record: presenting-issue keywords, observations, suggestibility scores, techniques
used, suggestions given (mode + payload id), PHS status, homework, referral/consent artifacts.
Required forms on file before session 1: Acknowledgment of Services & Fees, Client Application,
Clinical Intake. Referral-lane clients additionally require the written referral (see axes.yaml).

## Scope guardrails (B&P §2908 / SB 577)

- Lanes: `vocational` and `avocational` self-improvement need no referral.
- `referral_health` lane requires a written referral from a licensed CA physician, dentist,
  psychologist, or other authorized licensee **on file before booking** (platform booking gate).
- No diagnostic, "treatment", or psychotherapeutic language anywhere in scripts or notes.
- Risk triggers (self-harm, abuse, psychosis indicators) → stop, refer out per Risk Assessment
  & Crisis Intervention protocol; never scripted around.
- Minors: guardian consent + guardian present; assent obtained from the child.
