---
Non-negotiables baked into every design decision.

| # | Constraint | Design consequence |
|---|---|---|
| C1 | Portal reps ≠ HMI credit; the 24 client contacts must be real humans logged in HMI's Client Contact Log | Dual ledger (`sim` vs `real`); the real gap renders on every screen |
| C2 | SAP hard stop **Dec 10 2026** | P0 ships in days; 3D never blocks training value |
| C3 | Practitioner avatars | Fictional composite archetypes only; no simulation of real named people; no cloned voices without written consent |
| C4 | Scope of practice (B&P §2908 / SB 577) | Three-lane scenarios; referral gate is part of the drill; risk triggers train STOP-and-refer, never the workaround |
| C5 | Data | Sim transcripts with fictional clients ≠ PHI → light posture. Real practicum recordings never enter the academy DB — they belong to the CMIA-hardened practice platform |
| C6 | Copyright | Panorama/HMI text is never stored or displayed; scripts are original v1.1 wording; workbooks stay on disk |
