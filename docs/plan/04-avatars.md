Five classes, each a YAML persona card: identity, voice, style rules, knowledge scope, refusal rules
(clients never break character; instructors cite-or-decline on HMI facts).

| Class | Engine | Mechanics |
|---|---|---|
| **Client** | Profile axes (sex · age · occupation · E&P sugg · E&P rel) + issue plan + responsiveness model | Suggestibility → arm-rise speed, nod latency at `await_*`, hand-vs-arm answer; resistance / abreaction events at difficulty ≥ 3; free-talk intake via constrained persona LLM |
| **Peer student** | Duet mode | Swaps operator/subject; quiz sparring; deliberate mistakes at higher difficulty |
| **Instructor** | Case-conference sim | You present per Case History Series structure; avatar probes, challenges, assigns follow-up |
| **Coach/Mentor** | Examiner + planner | Mock PSR against the 11-item checklist; weekly ledger review vs season pass; unlocks nodes |
| **Practitioner archetypes** | Shadow mode | Fictional composites ("Kappasinian Classic", "Ericksonian Indirect", "Imagery-Led") demo sessions; you annotate the how/why |

Difficulty dial 1→5: compliant → slow responder → wrong-limb answers → mid-induction interruptions →
mild abreaction + referral-lane trap requiring STOP.
